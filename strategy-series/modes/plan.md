# Mode: plan

**What it does:** proposes the series calendar. It stays thin on purpose: the value is in the
sequence and the prep time, not in booking meetings.

## Step 1 — Propose the sequence

Start from the period, the ratify date and the themes in the profile. Default shape, adjusted to
what the person said:

| Order | Session | Why it goes here |
|---|---|---|
| 1 | **Look back** | What last period's numbers and decisions actually say. Sets the baseline |
| 2 to n−1 | **One theme each** | One session per area that needs real decisions (programs, money, people, operations) |
| n | **Ratify** | Agree the goals. Nothing new is raised here |

Rules:
- **A theme earns a session only if it carries decisions.** An area that's all updates goes in a
  pre-read, not a meeting.
- **Leave a gap before the last session.** The drafter needs time to write the full draft
  (goals mode, final pass). A week is a good default.
- **Two hours is the most a single session can hold** before decisions get worse. Split anything
  bigger.
- **Name what is solo.** Work one person can decide alone goes in `solo_streams`, not on an agenda.

## Step 2 — Propose prep blocks

For each session, one prep block for the drafter (about 2 days before, 45 to 60 minutes) and the
date the pre-read goes out (at least 2 working days before).

## Step 3 — Stage it, then stop

Show the calendar as one table: session, date, length, theme, prep block, pre-read date. Run the
edit pass. On "go", write the sessions into the profile. Create calendar holds only if the person
asks and approves the exact invites; this mode never sends invitations by itself.
