# Practice meeting: Maple Street Collective

A made-up volunteer org, made-up people, and a 2½-minute standup written to trip every rule in the
skill. Use it for the practice run at the end of setup, or to see what the skill does before you
point it at a real meeting.

**How to run it:** paste the config from setup, then paste the tracker rows and the transcript below
and say "triage this meeting". Stage the review only. Then compare it with the answer key.

## Answer key

| # | What was said | A correct run | The rule it tests |
|---|---|---|---|
| 1 | Confirmation email shows Eastern time | 🐞 Feedback row, plus a linked fix task | A bug goes to the bug list first, then a fix task |
| 2 | "Move orientations to Saturdays" | ⛔ Contradicts the Tuesday decision (Sept 30). Write nothing; flag it | Reversals get flagged, not quietly written |
| 3 | "One email address volunteers can write to" | ⚠️ Likely duplicate of "Set up a shared inbox". Skip, note it on the existing task | Match on meaning, not words |
| 4 | Room for the Nov 5 phone bank | ⚠️ Duplicate of "Book a room". Note it, and remind in the recap because Friday is the deadline | A time-sensitive duplicate still gets a reminder |
| 5 | Priya's phone-bank one-pager by Friday | ✅ New task (Priya) plus a placeholder deliverable, "Not created yet", linked | The catalog shows an asset the moment it's promised |
| 6 | No-show section in the host guide | ✅ New task (Marcus), linked to the existing host guide, flagged needs approval before it goes to hosts | "Existing" isn't "approved" |
| 7 | Text reminders, not just email | ⚡ Decision by Dana, with Marcus and Priya agreeing. Why: the email-only no-show rate | Decisions record who and why |
| 8 | Do returning volunteers re-sign? | ❓ Open question. No owner, no next step | Question or action? Question |
| 9 | Theo's sign-in sheet | Theo goes in the notes and the owner stays blank, or Marcus owns a follow-up task | Only real people own records |
| 10 | "Theo's been a little flaky" | Internal on anything that carries it, or left out entirely | Never guess public |
| 11 | Election night watch party | 🏗️ Possible new project. Proposed, not created | Never create a project automatically |
| 12 | Podcast someday | Skipped, or at most a someday idea | High bar |
| 13 | Jess's birthday | Skipped | Small talk |

If your run misses one, that's useful: note which rule it missed before you trust it with a real meeting.
